# Therapy With Rachel

Marketing site for Therapy With Rachel, PLLC — Rachel Crickmar, MSW, LCSWA.

**Stack:** Next.js · Sanity · Vercel  
**Accounts:** Use Rachel's own GitHub, Vercel, and Sanity — see [SETUP.md](./SETUP.md).

## Quick start

```bash
cp .env.example .env.local
npm install
npm run dev
```

The site runs with built-in fallback content even before Sanity is connected. Contact form submissions require Rachel's Sanity write token.

## Pages

- `/` — Home (services + interest form)
- `/about` — About Rachel + services + endorsements
- `/rates` — Fees, insurance, Thrizer widget slot
- `/blog` — Articles from Sanity (sample post until CMS is filled)
- `/contact` — Get in touch
- `/privacy` — Form privacy notes
- `/admin` — Easy Sanity editor (login with Rachel’s Sanity account)

## Design

Calm eucalyptus/mist palette, Newsreader + Plus Jakarta Sans, personal solo-therapist layout (not corporate clinic).
